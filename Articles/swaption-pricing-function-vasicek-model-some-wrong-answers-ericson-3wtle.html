The Vasicek model is a one-factor interest rate model that can be used to price swaptions. The pricing function for a swaption using the Vasicek model can be written as:

C = E[e^(-rT) (1 - L(T)) (1 - K/S(T)) ]

Where:

  • C is the value of the swaption

  • E is the expectation operator

  • r is the short rate

  • T is time to maturity of the swaption

  • L(T) is the probability of the short rate being below the strike rate at time T

  • K is the strike rate

  • S(T) is the forward rate at time T

The probability L(T) can be calculated using the Vasicek model, which is a two-parameter model that describes the evolution of the short rate over time. The model assumes that the short rate follows a mean-reverting process with a mean rate and a volatility. The probability L(T) can be calculated using the following formula:

L(T) = N(d1)

Where:

  • N(d1) is the cumulative normal distribution function with argument d1

  • d1 = (log(K/S(0)) - (r - rho) T) / (sigma sqrt(T))

Where:

  • K is the strike rate

  • S(0) is the forward rate at time 0

  • r is the short rate at time 0

  • rho is the mean reversion rate of the short rate

  • sigma is the volatility of the short rate

  • T is the time to maturity of the swaption

The forward rate S(T) can be calculated using the following formula:

S(T) = S(0) exp(-(r - rho) T)

The swaption price can then be calculated using the Black-Scholes formula, which is a closed-form solution for pricing options on assets that follow a geometric Brownian motion. The Black-Scholes formula is:

C = S(0) N(d1) - K e^(-rT) * N(d2)

Where:

  • N(d1) and N(d2) are the cumulative normal distribution functions with arguments d1 and d2, respectively

  • d2 = d1 - (r - rho) * T

This is a basic outline of how to price a swaption using the Vasicek model. The specific details of the calculation will depend on the particulars of the model and the swaption being priced.
