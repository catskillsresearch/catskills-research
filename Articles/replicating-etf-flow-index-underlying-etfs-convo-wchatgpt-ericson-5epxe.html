Suppose we want to replicate FLW from the 100 underlying constituent ETFs.  They have very low correlation with the flow index. So a simple multiple regression on some segment of the underlying history will not give a good approximation.
We can rephrase this problem ("prompt it") as follows:
We have a Pandas dataframe df with a datetime index, 100 columns of independent variables X and 1 column of dependent variable y. All variables are positive. Let W=10 be a window. As output variables for a neural net, on day i-1 we will predict 100 columns F[i-1] such that F[i-1].dot(X[i-1]) is a good approximation for y[i]. The prediction will use some kind of neural net which is re-fit every timestep using the true value of y[i]. Please write the code for this in Python.
It turns out (thanks to a combination of back and forth between Claude.ai, which cut out on me, and ChatGPT), that a simple 3-layer fully connected neural network consisting of a dense 64 node RELU layer followed by a dense 32 node RELU layer and a 1 node dense layer with a lookback window of 10 days and a refit of the neural network of the predicted price versus the realized price will do the trick. I was quite surprised that I could get such a tight fit because it took a while to get the incantation right and the ETF returns really have only a very 2nd order sort of reaction to fund flows.  Regression definitely doesn't work.  Fancier neural nets like LSTM and GRU didn't work that well.  In this the simple 3 layer net was the best.
This is supposed to replicate the flow index ETF previsibly, that is, with no future information at the time the portfolio composition is determined just prior to the end of the trading day, so that the changed value under returns realized the next day cause the portfolio value to be close to the true value for FLW.
