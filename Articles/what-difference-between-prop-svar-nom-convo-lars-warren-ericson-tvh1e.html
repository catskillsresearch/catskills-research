What is the difference between a PROP, an SVAR and a NOM?

There are three types of symbols in the signature of a hybrid language:

PROP (Propositional symbols):

  • Denoted as {p, q, r, ...}

  • A denumerably infinite set

  • Used to represent propositions

SVAR (State variables):

  • Denoted as {x, y, z, ...}

  • A denumerably infinite set

  • Can be bound by quantifiers

  • Also function as propositional symbols

  • Intended to act as labels for states in a graph

  • Their interpretation is given by assignment functions

NOM (Nominal symbols):

  • Denoted as {i, j, k, ...}

  • A finite or denumerably infinite set

  • Intended to function as labels for states

  • In standard models, they are evaluated as true at just one unique state

The key differences are:

  • PROP are traditional propositional symbols.

  • SVAR are a hybrid between variables and propositions. They can be bound by quantifiers but also function as propositional symbols.

  • NOM are meant to act as unique labels for individual states in the model.

Together, SVAR and NOM make up the set of "state symbols" in the hybrid language. The addition of NOM and the dual nature of SVAR are what distinguish hybrid logic from regular modal logic
