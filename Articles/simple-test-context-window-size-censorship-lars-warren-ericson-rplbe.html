Simple test of context window size and censorship

Created on 2025-02-06 01:07

Published on 2025-02-06 01:36

This something I just noticed. It is easy to test. I put in a CSV file with 670 lines (header + 669 rows, 104319 characters) and I asked it to tell me how many lines were in the file. The files listed a variety of forecasting questions, some with geopolitical content. The LLMs work with code inputs that can be pretty long so I didn't think it would be a problem. It turns out none of the LLMs I tried could count the file, for various reasons. The first 5 I tried just wouldn't deal with it:

  • Google Gemini. Only allows image upload.

  • X.ai (Grok). You have to pay to add an attachment. No thanks.

  • Claude.ai. Refused to upload the file, saying it was 29% over the length limit.

  • ChatGPT. "Unknown error occurred"

  • Meta.ai. "Unsupported file type"

I tried these which accepted the file, with prompt "How many lines are in the attached file?" and got

  • Microsoft Copilot. "The attached file contains 490 lines."

  • Perplexity.ai. "The attached file contains 100 lines of data. Each line represents a different forecast question, along with associated scores, dates, and probabilities."

The interesting case, because it brings up the novel feature of censorship is this new market-shattering entry into the world of LLMs:

  • DeepSeek, from the People's Republic of China y'all, caveat emptor, allowed the upload saying "May violate terms" and then refused the prompt, saying "Remove failed files to submit."
