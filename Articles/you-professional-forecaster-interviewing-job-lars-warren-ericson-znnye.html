Metaculus has opened up a great new AI forecasting competition. I jumped on it and looked at the forecasting demo, the warmup questions page, the Discord channel, and the example notebook. The notebook calls for several API keys, some of which require a budget for more than trial use. This set me off on a search for chatbots that incorporate web search in their queries and have free Python APIs. Currently only HuggingChat qualifies. HuggingChat says it uses Hugging Face's own web search engine, which I didn't know existed.

I think HuggingChat is wrong about itself: the HuggingChat API actually mentions something called serper, which offers 2500 free queries without a credit card, which is probably enough for the Metaculus challenge.

I very slightly tuned the prompt on the forecasting demo page: I took the stock query and added a few instructions:

  • Write forecast rationales in 200 words or less.

  • Don't use forecasting predictions from Metaculus or any other crowd forecasting site.

I tried the prompt out on some new-to-me chatbots, HuggingChat and Claude, and some familiar ones, Meta AI, Google Gemini, Microsoft Copilot and Perplexity AI. Note that Meta AI currently permits some free workarounds to get to their API. (These avenues tend to get closed off as a service matures, but left open at the start.)
