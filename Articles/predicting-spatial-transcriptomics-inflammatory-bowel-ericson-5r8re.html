I am working on the CrunchDAO Broad Institute Autoimmune Disease challenge, part 1, on Irritable Bowel Disease. These are some notes to help me think about the topic.

In part 1 we are given 7 tissue images from different patient cases where the diagnoses are Diverticulitis,

Ulcerative Colitis Not Inflamed,

and Ulcerative Colitis Inflamed

The tissues are biopsied from the colon. Each image depicts thousands of cells of various types. The challenge uses the Scikit Image regionprops function to locate the centroids of the cells. We are given spatial transcriptomics readouts of 460 genes at the locus of each of these centroids, for the 32x32x3 (RGB) patch at that locus. The part 1 task is to accurately predict the spatial transcriptomics of a given patch.

Although looking at these patches, center of what is not so clear, me not being a biologist, I don't know whether I am looking at one cell or part of a cell or many cells or what, but this is the setup for the challenge:

We are given a base model to improve on which uses Resnet50's 224x224 image encoder to reduce the image to a feature vector in latent space which we hope encodes the necessary information to predict the gene expression. (I still haven't figured out why 224x224 matches well with a 32x32x3 image, it's on my to-do list to worry about.)

Here is a t-SNE visualization of the vectors of 460 gene expressions which are the spatial transcriptomics of a balanced set of test patch images, differentiated by pathology:

We speculate that the islands correspond to distinct cell types or cell populations imaged in the patches, so that different kinds of cells will naturally have different gene expression profiles. Within each cell type, we will for some but not all cell types see different gene expressions representing the pathology. I am told by challenge participant Kalin that the islands would be less fuzzy when corrected for the batch effect. Each cell image above is considered a batch, because it is broken down into a batch of patches for which the spatial transcriptomics analysis is run. (So each transcriptomics analysis is a batch.)

The base model uses Ridge Regression to map from feature vector to gene expression in the test data after fitting feature vectors to gene vectors in the training data. It's that easy. Except that the base model has a correlation of about 14% with the ground truth gene expression profiles. To be improved on (100% is best).

In exploring this problem we replace the Ridge Regression with a Multilayer Perceptron model (MLP) as a regression model. The model takes the embedding and predicts a gene expression. We compare this with the ground truth gene expression. Here is a t-SNE visualization of the difference for a model with just a little training (100 epochs):

We wonder whether the MLP has the capacity to represent the mapping from embedding to transcriptomics. To test this, we overfit the MLP to the test set and then run it on the test set. What we see is pretty good but not perfect capture of the mapping for 12,000 balance test samples. We can define a loss function for this and then, from a representation standpoint, we would want to start with an embedding-to-transcriptomics model which achieves the least lossy representation. The loss function is easy because there is a 1-1 mapping between predicted and ground truth points under the t-SNE mapping, so we can just take the Euclidean distance between each point and sum up the distances and that's the loss.

Of course, if the embedding is too coarse or lacking in sufficient features, we will not get there. So in addition to varying the regression model, we will also want to vary the embedding model, comparing Resnet, Densenet, ViT and so on. We could also look at features available from the regionprops function that was used to obtain the patch centroids. At least this was an idea I had to start with, but looking at the patches above, it is clear that each patch has multiple cells, so regionprops can't really give us salient dimensions of individual cells in the patch which might at least identify the cell type. A good embedding might actually do this, so tactically we drop the regionprops idea and will just search for better embeddings under the t-SNE loss metric idea.

We can also break down the above performance metric by pathology, to see whether the given embedding/regression pair performs better under t-SNE distance between prediction and ground truth for individual pathologies. The way forward for me is to

  1. Find the most performant embedding and regression pair under the test set overfit t-SNE distance metric.

  2. Find hyperparameters to optimize this pair under the t-SNE distance between ground truth and predicted gene expression for the test set.
